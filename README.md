## The entry

> My boss calls it a flat hierarchy, which is why I report to seven people who all think they're my boss.

A single line about office life, 103 characters, written by `main.py` to `/output/entry.txt`. The joke turns on a true office observation: a company that brags about having no hierarchy still hands you a stack of managers, each one acting like the boss. The flat hierarchy is the reason for the seven bosses, not the cure for them.

## Run it

Run `main.py` with Python 3. It writes the entry to `/output/entry.txt`.
